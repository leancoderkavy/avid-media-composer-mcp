# Saved effect parameter fingerprints

Opaque TKFX nodes may include `effect.parametersFingerprint` and `effect.keyframesFingerprint`, each containing `schema: 1` and a SHA-256 digest. Saved snapshot range reads retain these values, and snapshot diffs compare them. This lets a same-name effect report changed captured parameters even when its readable LUT declaration is unchanged.

The Python indexer fingerprints supported saved ParameterItem, CFUserParam, EffectParamList and EffectParam declarations. Type-tagged values distinguish numbers, booleans, UUIDs, strings and bytes. Object property keys are sorted; sequence order is preserved. Byte arrays contribute their length and SHA-256. Root handles and object instance IDs are excluded. Saved parameter fields such as keyframe selection are included, so a changed fingerprint need not imply changed rendered pixels.

Traversal stops at 2,048 values, 16 nesting levels, 1,024 collection entries, 128 object properties, 4,096 characters per string and 1 MiB of aggregate string/byte content. Unsupported classes, cycles exceeding depth, nonfinite values and oversized data produce no fingerprint. Absence means unrecorded, absent or unsupported data; it does not mean an empty or unchanged effect. Existing snapshots without fingerprints remain readable.

These fingerprints do not decode effect math, track nesting, media references, all effect properties or color transforms. Nodes remain opaque and snapshot coverage remains incomplete. Matching hashes are evidence about the supported captured declarations, not full bin or rendered equivalence. No offline project mutation or automatic color correction is added to the connector.
