Quick start

Run beside your Avid project.

Read-only inspection is available now

git clone https://github.com/leancoderkavy/avid-media-composer-mcp.git
cd avid-media-composer-mcp
npm install
python -m pip install -r python/requirements.txt
npm run build
node dist/index.js

Requires Node.js 20 or newer. Python is used for AVB and AAF analysis, and ffprobe is optional for media metadata.

Frequently asked questions

Clear boundaries for Avid automation.

Is there an MCP server for Avid Media Composer?

Yes. This project provides a working MCP server for read-only project analysis. Guarded live editing requires a compatible Avid Extension bridge.

Which Avid file formats can it analyze?

AVB, AAF, ALE, EDL, AVP and AVS configuration evidence, project trees, locks, and media metadata are supported through bounded tools.

Does it modify source media?

No. Offline analysis is read-only. Live changes require explicit authority, an exact confirmation token, and a connected extension bridge.

Is this an official Avid product?

No. It is an independent MIT-licensed project and is not affiliated with or endorsed by Avid Technology, Inc.
